# Portfólio de Iure Oliveira

Site estático feito com HTML e CSS para publicar pelo GitHub Pages.

## Antes de publicar

1. Confira os dados pessoais, curso, datas e competências.
2. Atualize o link do LinkedIn caso o endereço público esteja diferente.
3. Acrescente projetos acadêmicos ou pessoais reais, com links para o código ou demonstração.
4. Remova qualquer competência que não consiga explicar ou demonstrar em uma conversa técnica.

## Publicação no GitHub Pages

1. Crie um repositório público chamado `iure-go.github.io` na conta `iure-go`.
2. Envie `index.html` e `styles.css` para a raiz do repositório.
3. Em **Settings → Pages**, escolha a publicação a partir da branch `main` e da pasta `/ (root)`.
4. O site deverá ficar disponível em `https://iure-go.github.io/` depois que a publicação terminar.

Esta etapa não cria nem altera repositórios online. Os arquivos precisam ser revisados antes do envio.
