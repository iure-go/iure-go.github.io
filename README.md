# Portfólio de Iure Oliveira

Portfólio estático de Iure Oliveira dos Santos, publicado pelo GitHub Pages. O site principal usa HTML e CSS; as demonstrações incluem um organizador de estudos em JavaScript e uma seleção de projetos acadêmicos em C.

## Antes de publicar

1. Confira os dados pessoais, curso, datas e competências.
2. Atualize o link do LinkedIn caso o endereço público esteja diferente.
3. Os projetos atualmente descritos ficam em `projetos/organizador-estudos/` e `projetos/c/`.
4. Acrescente outros projetos conforme forem concluídos, com objetivo, tecnologias e links verificáveis.
5. Descreva com clareza o que foi feito e mantenha as competências alinhadas ao que consegue demonstrar.

## Publicação no GitHub Pages

1. No repositório público `iure-go/iure-go.github.io`, atualize `index.html`, `styles.css` e `README.md` na raiz.
2. Envie também as pastas `projetos/organizador-estudos/` e `projetos/c/` completas, mantendo a estrutura de diretórios.
3. Em **Settings → Pages**, a fonte deve continuar na branch `main` e pasta `/ (root)`.
4. Após a publicação, a página principal ficará em `https://iure-go.github.io/`; as demonstrações e projetos estarão em `https://iure-go.github.io/projetos/organizador-estudos/` e `https://iure-go.github.io/projetos/c/`.

O conteúdo local está pronto para revisão e envio ao repositório. Atualizar estes arquivos não envia as mudanças automaticamente ao GitHub.
