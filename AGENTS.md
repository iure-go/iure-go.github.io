# Instruções para manutenção do portfólio

- Sempre que um projeto for criado, adicionado ou removido, atualize o `README.md` no mesmo conjunto de alterações.
- Na tabela **Projetos em destaque**, mantenha nome, descrição curta, tecnologias/conceitos e links válidos para demonstração e código.
- Se o projeto tiver uma demonstração web, mantenha também o catálogo em `projetos/demos-web/index.html` e a seção de projetos em `index.html` sincronizados.
- Preserve os links de contato e os dados pessoais já registrados no README.
