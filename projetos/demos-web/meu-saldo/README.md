# Meu Saldo — demonstração web

Versão demonstrativa no navegador do projeto acadêmico Meu Saldo. Apresenta resumo por dia, semana, mês e ano, cadastro de lançamentos, categorias, limite mensal e relatório.

A tela começa com valores fictícios usados nas capturas do projeto (outubro de 2026). Os lançamentos e o limite são mantidos somente na memória da página e desaparecem ao recarregar. Esta demonstração não se conecta à API e não realiza operações financeiras.
