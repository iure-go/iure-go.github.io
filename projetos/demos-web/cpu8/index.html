04 / MEMÓRIA PRINCIPAL

RAM de 64 bytes

programa dados

Cada instrução ocupa dois bytes (opcode e operando). O programa usa endereços 00–2F; a área de dados fica em 30–3F (48–63 em decimal).

05 / CONCEITOS

O que o projeto demonstra

Representação binária

Os valores têm 8 bits e variam de 0 a 255. A memória mostra cada byte em hexadecimal.

Registradores

O PC localiza a próxima instrução; o IR guarda o opcode; A participa das operações da ULA.

ULA e flags

Soma, subtração e operações lógicas atualizam A e as flags zero (Z) e carry/borrow (C).

Fluxo de controle

JMP altera o PC e JZ desvia quando Z está ativa.

Ver conjunto de instruções
  • LDI n carrega um valor imediato no acumulador.
  • ADDI n e SUBI n somam ou subtraem um valor imediato.
  • LOAD a lê RAM[a]; STORE a grava em RAM[a].
  • ANDI n e ORI n fazem operações bit a bit.
  • JMP a, JZ a, OUT e HLT controlam o fluxo, exibem A e encerram o programa.
