# Matemática em prática

Demonstração didática criada para a disciplina **Matemática Básica**. A página oferece ferramentas interativas para revisar operações fundamentais, frações, porcentagem e regra de três simples.

## Como usar

Abra `index.html` em um navegador. Não é necessário instalar dependências. Cada ferramenta vem com valores de exemplo que podem ser alterados e recalculados.

## Ferramentas

- Calculadora com adição, subtração, multiplicação e divisão.
- Operações com frações e simplificação do resultado pelo máximo divisor comum.
- Cálculo de uma porcentagem de um valor.
- Regra de três simples direta com explicação do produto cruzado.

## Conceitos praticados

Operações aritméticas, números racionais, frações equivalentes, máximo divisor comum, razão, proporção e porcentagem.

## Tecnologias

HTML · CSS · JavaScript

## Escopo e limitações

Projeto de revisão didática, sem backend e sem armazenamento de dados. A regra de três apresentada é direta; casos de proporcionalidade inversa não fazem parte desta versão. Consulte `conceitos.md` para as fórmulas usadas.
