CONCEITOS EM FOCO

O que cada ferramenta pratica

Ordem das operações

Adição, subtração, multiplicação e divisão são operações fundamentais. A calculadora permite testar cada uma isoladamente.

Frações equivalentes

Para somar ou subtrair, use denominadores comuns. Para multiplicar, multiplique numeradores e denominadores; simplifique pelo MDC.

Porcentagem

Por cento significa “a cada cem”. Para calcular p% de um valor, multiplique o valor por p/100.

Proporcionalidade

Na regra de três direta, a razão se mantém. O produto cruzado permite encontrar o termo desconhecido.
