# IHC Lab — Interface Homem Computador

Laboratório interativo para explorar princípios de usabilidade e acessibilidade em uma solicitação de suporte universitário.

## O que a demonstração apresenta

- Um fluxo de solicitação de suporte com campos obrigatórios e confirmação após o envio.
- Preferências de uso: alto contraste, texto ampliado e perfil de navegação por teclado.
- Uma lista de verificação baseada em princípios heurísticos de usabilidade.
- Uma escala rápida para registrar a percepção de facilidade da tarefa.
- Conteúdo responsivo, rótulos associados aos campos, mensagens com região de status e foco visível.

Os registros são fictícios e permanecem apenas no navegador. A nota e as marcações não são enviadas nem armazenadas.

## Conceitos estudados

- Design centrado nas pessoas e contexto de uso.
- Usabilidade, feedback e prevenção de erros.
- Acessibilidade e diferentes formas de interação.
- Avaliação heurística e teste de tarefas.

## Como executar

Abra `index.html` no navegador. O projeto usa HTML, CSS e JavaScript sem dependências externas.

## Estrutura

- `index.html`: conteúdo e controles acessíveis.
- `styles.css`: layout responsivo, estados visuais e preferências de acessibilidade.
- `app.js`: validação do formulário, atualização da avaliação e controles da demonstração.

Projeto didático desenvolvido para a disciplina de Interface Homem Computador.
