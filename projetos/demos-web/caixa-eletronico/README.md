# Simulador de caixa eletrônico — demonstração web

Versão para navegador do exercício de Construção de Algoritmos. O saldo inicia em R$ 0,00 e é mantido apenas na memória da página durante esta sessão.

## Como usar

- Informe um valor positivo e selecione **Depositar** ou **Sacar**.
- Use **Consultar saldo** para mostrar o saldo atual.
- Saques acima do saldo disponível são recusados.
- **Reiniciar simulador** volta o saldo para R$ 0,00.

Esta demonstração não realiza operações bancárias reais nem envia ou persiste informações. O código original em C está na pasta `../../c/caixa-eletronico/`.
