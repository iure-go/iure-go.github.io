# EngSoft Lab · Engenharia de Software I

Laboratório didático interativo para explorar um ciclo de desenvolvimento de software usando um estudo de caso fictício: reservas de salas de estudo universitárias.

## O que dá para explorar

- Navegar pelas etapas de requisitos, projeto, construção e verificação.
- Inspecionar requisitos funcionais e de qualidade escritos como histórias de usuário.
- Conferir critérios de aceitação e ajustar prioridade usando MoSCoW.
- Montar uma sprint com estimativas relativas e observar o limite de capacidade.
- Seguir a rastreabilidade de cada requisito até seu cenário de teste.
- Simular aprovação ou falha de testes e acompanhar a cobertura aprovada.

## Executar

Abra index.html no navegador. O projeto usa HTML, CSS e JavaScript sem dependências externas ou instalação.

## Estrutura

- index.html: conteúdo, seções e controles acessíveis.
- styles.css: identidade visual responsiva.
- app.js: requisitos de exemplo, estado da interface e cálculos interativos.

Os dados e resultados são apenas exemplos locais. Não são enviados para um servidor e não representam um sistema de reservas em produção. Os comentários em app.js indicam como trocar os requisitos e adaptar as interações.

## Conceitos demonstrados

Engenharia de requisitos, histórias de usuário, requisitos funcionais e de qualidade, critérios de aceitação, priorização MoSCoW, planejamento iterativo, estimativa relativa, rastreabilidade e testes de aceitação.
