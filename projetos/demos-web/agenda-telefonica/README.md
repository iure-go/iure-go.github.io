# Agenda telefônica — demonstração web

Versão para navegador do projeto acadêmico de agenda telefônica. Permite adicionar contatos, pesquisar pelo nome, navegar pela lista e remover um contato ou limpar a agenda.

Os registros ficam somente na memória da página e desaparecem ao recarregar ou fechar o navegador. Use apenas dados fictícios; a demonstração não salva contatos em arquivo nem no armazenamento local do navegador.

Acesse [a demonstração no portfólio](https://iure-go.github.io/projetos/demos-web/agenda-telefonica/) ou veja o [código original em C](../../c/agenda-telefonica/).
