# Operações com polinômios — demonstração web

Versão interativa do projeto acadêmico de operações com polinômios. Informe um termo por linha como `3,2` (coeficiente 3, expoente 2), crie P1 e P2 e depois escolha somar, multiplicar ou avaliar para um valor de x.

A demo combina coeficientes de termos com expoentes iguais e organiza os termos do maior para o menor expoente. Para manter a demonstração responsiva, ela aceita até 20 termos por polinômio, coeficientes entre −10.000 e 10.000, expoentes de 0 a 20 e valores de x entre −100 e 100. As contas usam inteiros de precisão arbitrária no JavaScript.

Abra `index.html` no navegador ou acesse a demonstração pelo [portfólio](https://iure-go.github.io/projetos/demos-web/polinomios/). O código original em C permanece em `../../c/polinomios/`.
