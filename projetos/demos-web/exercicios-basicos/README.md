# Exercícios básicos — demonstrações web

Três exercícios introdutórios de Construção de Algoritmos em versões interativas para navegador:

- **Classificar número:** identifica valores positivos, negativos e zero.
- **Somar dois números:** calcula a soma de dois valores informados.
- **Fatorial:** calcula o fatorial de um inteiro de 0 a 18.

Acesse [a demonstração publicada](https://iure-go.github.io/projetos/demos-web/exercicios-basicos/) ou consulte os exemplos correspondentes na [pasta de exercícios em C](../../c/exercicios/).
