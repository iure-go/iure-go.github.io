# Demonstrações web dos projetos acadêmicos

Esta pasta reúne versões para navegador dos projetos acadêmicos. Os fontes originais em C permanecem em `projetos/c/`.

## Demonstrações disponíveis

- [Meu Saldo](meu-saldo/): painel de finanças pessoais com dados fictícios e sem persistência no navegador.
- [Jogo de adivinhação](adivinhacao/): implementação em HTML, CSS e JavaScript com dicas, validação de palpites, contador e opção de novo jogo. O código original em C está em `../c/adivinhacao/`.
- [Simulador de caixa eletrônico](caixa-eletronico/): versão web com consulta de saldo, depósitos, saques e validação de saldo. O código original em C está em `../c/caixa-eletronico/`.
- [Operações com polinômios](polinomios/): cria dois polinômios e permite somar, multiplicar e avaliar. O código original em C está em `../c/polinomios/`.
- [Agenda telefônica](agenda-telefonica/): cadastra, pesquisa, navega e remove contatos fictícios em memória. O código original em C está em `../c/agenda-telefonica/`.
- [Exercícios básicos](exercicios-basicos/): classifica números, soma dois valores e calcula fatoriais. Os exemplos originais em C estão em `../c/exercicios/`.
- [Alocação dinâmica](memoria-dinamica/): visualização didática da diferença entre `malloc`, `calloc` e `free`.

Acesse a página [Demonstrações web](https://iure-go.github.io/projetos/demos-web/) no portfólio para abrir os projetos. Novas versões web podem ser organizadas em subpastas sem substituir os arquivos acadêmicos originais.
