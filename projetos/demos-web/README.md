# Demonstrações web dos projetos acadêmicos

Esta pasta reúne versões para navegador dos projetos acadêmicos. Os fontes originais em C permanecem em `projetos/c/`.

## Demonstrações disponíveis

- [Jogo de adivinhação](adivinhacao/): implementação em HTML, CSS e JavaScript com dicas, validação de palpites, contador e opção de novo jogo. O código original em C está em `../c/adivinhacao/`.

Acesse a página [Demonstrações web](https://iure-go.github.io/projetos/demos-web/) no portfólio para abrir os projetos. Novas versões web podem ser organizadas em subpastas sem substituir os arquivos acadêmicos originais.
