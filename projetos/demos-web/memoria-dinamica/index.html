O que a visualização representa

  • malloc reserva espaço, mas não inicializa os valores. O conteúdo é indeterminado; o programa C deve gravar um valor antes de ler a posição.
  • calloc reserva espaço para várias posições e inicializa os bytes com zero.
  • free libera a memória reservada. Depois disso, aquelas posições deixam de pertencer ao vetor.

Esta é uma ilustração didática feita em JavaScript; ela não aloca memória C nem mostra endereços ou valores reais da memória do computador.
