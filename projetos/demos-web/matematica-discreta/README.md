# Laboratório Discreto

Projeto didático interativo para a disciplina de **Matemática Discreta**. Reúne três exploradores que rodam inteiramente no navegador:

- Operações de conjuntos: união, interseção e diferenças.
- Tabelas-verdade para conjunção, disjunção, OU exclusivo, implicação e bicondicional.
- Verificação de reflexividade, simetria, antissimetria e transitividade em relações binárias finitas.

## Executar

Abra `index.html` em um navegador moderno. Não há dependências ou etapa de compilação.

## Estrutura

- `index.html`: interface e estrutura semântica.
- `styles.css`: identidade visual responsiva compartilhada com os outros projetos didáticos.
- `app.js`: operações e interações.
- `conceitos.md`: resumo dos conceitos matemáticos e suas relações com computação.

## Aprendizados demonstrados

Lógica booleana, operações com conjuntos, relações binárias, validação de entradas, renderização dinâmica, HTML semântico e CSS responsivo.

Os dados fornecidos nos formulários são processados apenas na memória da página; nada é enviado ou salvo.
