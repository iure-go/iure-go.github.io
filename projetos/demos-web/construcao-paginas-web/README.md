# PageLab — Construção de Páginas Web

Editor didático para experimentar a estrutura e o estilo de uma página web. Altere textos, cor e seções; visualize a página em tamanhos desktop e celular; e consulte ou copie o HTML gerado.

## Como executar

Abra `index.html` em um navegador moderno. Não há dependências, instalação, backend ou envio de dados.

## Recursos

- Editor de título, apresentação, texto “Sobre” e chamada para ação.
- Seletor de cor de destaque.
- Opções para incluir ou remover seções.
- Prévia responsiva em iframe isolado.
- Código HTML completo atualizado conforme as edições e opção de cópia.
- Notas didáticas sobre HTML semântico, CSS responsivo e eventos JavaScript.

## Tecnologias e conceitos

HTML5 · CSS3 · JavaScript · DOM · eventos · `srcdoc` · `iframe sandbox`

O texto digitado é escapado antes de ser inserido no documento gerado, e a prévia roda em um `iframe` sem permissões de script.
