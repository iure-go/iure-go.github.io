# Organizador de estudos

Projeto pessoal criado para praticar HTML, CSS e JavaScript. A aplicação permite cadastrar tarefas de estudo, marcar atividades como concluídas, filtrar a lista e remover tarefas. Os dados são persistidos localmente no navegador usando `localStorage`.

## Como usar

Abra `index.html` no navegador. Para publicar junto com o portfólio no GitHub Pages, envie esta pasta para `projetos/organizador-estudos/` no repositório `iure-go.github.io`.

## Tecnologias

- HTML semântico
- CSS responsivo
- JavaScript moderno
- `localStorage`
